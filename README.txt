ABIR PORTFOLIO WEBSITE
======================

FILES
- index.html : website structure
- style.css  : responsive styling
- script.js  : mobile navigation, reveal animations, skill filters, GitHub repo loader, CV preview
- assets/profile.jpeg : your profile picture
- cv.pdf : your Flutter Developer CV

HOW TO USE
1. Keep index.html, style.css, and script.js in the same folder.
2. Your profile photo is already included at assets/profile.jpeg and appears in the hero profile card.
3. Your CV is included as cv.pdf and linked from the CV section.
4. Open index.html in a browser. For best testing, use VS Code Live Server.
5. Upload all website files and the assets folder to your hosting/GitHub Pages to publish it.
